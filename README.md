# User Service

### Spark Learning LMS app service that handles 

- Student Registration
- Login and issues JWTs
- Users management API

### Users API Index

Pre-authorized API for additional security and role based access in service to protect user data

- /api/users - Base URL [GET]
- /{id}  [GET, PUT, DELETE]
- /add  [POST]
- /search
- /register
- /login
- /getUserProfile
